Connect to the local engine

  1. When this extension is inside LLMBar, it gets the pairing token from the app automatically.
  2. If the token field stays empty, click LLMBar ▸ Tools ▸ Browser Assistant · Safari. LLMBar starts the service and copies the token.
  3. Paste the copied token here with ⌘V, then press Connect.

The token stays in this browser's extension storage. It lets the extension talk to the local model and start or stop the engine — nothing else on your Mac. Pages you visit never see it.

Eyes

When the text model cannot see a canvas or screenshot, LLMBar temporarily uses this local vision model and then restores the text model. By default it chooses the best installed model that fits memory.

Google Workspace

Connect Sheets, Docs, Drive, Gmail and Calendar directly from the local service. Google tokens stay in macOS Keychain; this extension and the pages you visit never receive them.

Advanced setup for source builds

Official release builds can include a public Desktop OAuth client ID. If this build has none, create a Google Desktop OAuth client and paste its ID here. This ID is not a secret.

What the agent did

A local record of the agent's steps: what was proposed, approved, refused and done, and on which site. It holds no page text and no typed values, stays in this browser, and keeps the last 200 entries.
