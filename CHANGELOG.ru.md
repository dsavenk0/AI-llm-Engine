# История изменений

Заметные изменения AI-llm-Engine. Даты — 2026 год; релизов с тегами пока нет, всё ниже относится к линии 1.0.
English version: [CHANGELOG.md](CHANGELOG.md).

## Не выпущено — 12 октября

### Добавлено
- **GGUF на собственном MLX-декодере** (семейства llama / Qwen2 / Qwen3; Q4_0…Q8_0, Q4_K, Q5_K, Q6_K): веса при
  загрузке перепаковываются в квантизацию MLX, токенизатор и шаблон чата берутся из файла. Всё остальное по-прежнему
  идёт через llama.cpp за тем же API.
- **Правки активаций**: `--steer` / `--steer-alpha` и `./llm steer <repo|папка>` применяют направление на выходах
  слоёв, пишущих в residual; базовая модель, для которой сделана правка, скачивается вместе с ней (закреплённая
  ревизия).
- **LLM Voice** — отдельное нативное приложение: говорите или печатайте, прикладывайте файлы и картинки, слушайте
  короткие ответы; обычное окно с кнопками закрыть/свернуть, стекло в стиле LLMBar, своя иконка.
- **Редактор**: режимы агента (Manual / Edit automatically / Plan / Auto) и Effort, кольцо контекста с Compact,
  переименование и удаление чатов, откат изменений git (по файлу и *Discard all*) с подтверждением, цветовые темы и
  сниппеты Open VSX (по желанию), инструменты поиска в сети и генерации картинок.
- Спекулятивное декодирование по подстрокам промпта для маршрутов mlx-lm и GGUF (при отклонённом черновике кэш
  обрезается назад).
- Тесты: тестер мутаций (`tests/mutate.py`), тесты по эталону для каждого блочного формата GGUF, правила
  префиксного кэша, граничные случаи MCP / парсеров / картинок. Полный набор — больше 700 тестов.

### Изменено
- Картинки, отправленные модели без vision, отбрасываются с одной строкой-заметкой вместо ответа 400.
- Непригодные параметры запроса (`max_tokens`, `temperature`, `stop`…) дают 400 до того, как что-либо запустится.
- `--steer` на бэкенде mlx-lm — ошибка при старте, а не молчаливое игнорирование.
- `build-dmg.sh` пишет установщик в `docs/` — файл, который раздаёт сайт.

### Исправлено
- Редактор: колонка номеров строк больше не закрывает первые символы каждой строки после изменения размера окна, а у
  файла с завершающим переводом строки нет лишнего номера.
- Токен Hugging Face больше не пересылается на CDN, на который перенаправляет загрузка.
- Git: `paths` одной строкой больше не добавляет в индекс весь репозиторий; огромные diff обрезаются на 2 МБ.
- Вывод shell-инструмента ограничен (4 МБ на поток); web-запросы проверяют адрес узла после соединения.
- Клиент MCP: мусор между сообщениями, повторяющийся курсор, инструменты без имени, огромные результаты, упавшие
  серверы.
- Остановка внутри принятого спекулятивного черновика оставляла кэш длиннее поданных токенов.
- Генерация картинок: промпт, начинающийся с `--`, больше не читается как опция.

## 11 октября

### Добавлено
- **LLM Editor** — нативное Swift-приложение (по требованию): чат-ориентированный и классический вид, агент,
  который спрашивает перед правкой, git и GitHub, проблемы, терминал, предпросмотр, диктовка, темы, источник модели
  (другой OpenAI-совместимый сервер), модуль расширений.
- **Маршруты 1.75 бит** на одном Metal-ядре: PTQ1_0, TQ1_G128, JANG packed (экспериментально).
- **Необязательный бэкенд mlx-lm** для архитектур, которых нет в нативном движке, с маршрутизацией
  native / ptq1 / mlxlm.
- **Harness агента**: память проекта и автосжатие контекста, карта проекта и заметки сессии, поиск и чтение страниц,
  клиент MCP (stdio + streamable HTTP, пресеты Context7 и Stitch), `/fix-tests`, передача задач через `/workers`.
- **Бенчмарки**: 14 наборов с доверительными интервалами (GSM8K, MMLU, MMLU-Pro, ARC, HellaSwag, TruthfulQA,
  WinoGrande, KMMLU, C-Eval, MathQA, BBQ, SafetyBench, HumanEval, MBPP); код выполняется в песочнице.
- **Необязательная генерация картинок** через mflux (`./llm setup --images`, `/v1/images/generations`).
- Подключаемые парсеры рассуждений и вызовов инструментов с ручным переопределением; GGUF в папках, хранилища LM
  Studio и Ollama через llama.cpp; ModelScope как второй источник моделей; пауза и продолжение загрузок.
- LLMBar: маршруты и причины, настройки конкретной модели, удаление, Liquid Glass, прогресс чтения промпта, настройки.

### Изменено
- Любая MLX-квантизация загружается по формам тензоров; умолчание рассуждений берётся из шаблона модели.
- Префиксный кэш на SSD пишется только при сне и остановке; бюджет может быть `auto`.

### Исправлено
- Устаревшие pid-файлы, зависшие порты, таймауты команд; стоп-строки вырезаются из ответа; `/health` отвечает во
  сне; зацикленные ответы останавливаются (`repetition_penalty`); неполный файл не остаётся под итоговым именем.

## 10 октября
- Разбор памяти в LLMBar, понятнее настройки, скруглённая панель, своя иконка в строке меню; `/v1/stats`.
- Лендинг (Apple × Cyberpunk HUD) и ссылки на GitHub Releases.

## 9 октября

  меню (стеклянная панель под значком).
